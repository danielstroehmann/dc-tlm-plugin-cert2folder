# cert2folder: SSH Folder Plugin for DigiCert Trust Lifecycle Manager

An automation plugin for DigiCert Trust Lifecycle Manager (TLM) that rolls out, discovers and renews TLS
certificates in a directory on a remote host via SSH, laid out like certbot's `/etc/letsencrypt`, and runs a
configurable command after each deployment.

> **Status: concept, no plugin code yet.** Design and open decisions: [STATUS.md](STATUS.md).
